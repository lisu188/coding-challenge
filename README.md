# Coding Challenge Archive

A historical collection of programming-practice solutions from **Codility** and **HackerRank**.

This repository is kept public as an archive of algorithm/problem-solving exercises. It is **not** intended to represent a production codebase, reusable library or current coding style guide.

## Structure

- `src/codility/` — solutions to Codility-style exercises
- `src/hackerrank/` — solutions to HackerRank-style exercises

Problem statements belong to their respective platforms; this repository contains solution code and related working material only.
